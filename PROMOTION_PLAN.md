# Promotion Plan

This plan is for promoting Particle Multiverse OS as an open-source portfolio project.

## GitHub

- Add repository topics:
  `particle-system`, `tauri`, `desktop-app`, `ai-interface`, `creative-coding`, `cyberpunk`, `visual-effects`, `javascript`, `vite`.
- Pin the repository on your GitHub profile.
- Create a GitHub Release for `v2.0` with GIF, screenshots, setup exe, portable exe, and release notes.
- Add a short repository description:
  `Cinematic particle multiverse desktop app built with Tauri, Vite, JavaScript, Canvas, and WebGL-style effects.`

## Bilibili

- Video title:
  `我做了一个电影级粒子宇宙桌面 App：Particle Multiverse OS`
- Video structure:
  1. 3-second visual hook
  2. Show six worlds
  3. Show burst, voice, gesture, music response
  4. Show GitHub repo and release download
  5. Ask viewers to Star the project
- Tags:
  `创意编程`, `桌面软件`, `粒子系统`, `Tauri`, `前端开发`, `科幻UI`

## Douyin

## Xiaohongshu

- Post format:

  3. Short story: why you built it
  4. Tech stack
  5. GitHub link

  `做了一个科幻粒子宇宙桌面 App，已开源`

  `#独立开发`, `#开源项目`, `#创意编程`, `#前端开发`, `#桌面应用`
