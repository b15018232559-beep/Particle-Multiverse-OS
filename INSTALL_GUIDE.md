# Install Guide

## Installer

Run:

```text
outputs/Particle-Multiverse-OS-V10-Setup.exe
```

Follow the Windows installer prompts.

## Portable

Run:

```text
outputs/Particle-Multiverse-OS-V10-Portable.exe
```

The portable build starts the app directly without the installer.

## Requirements

- Windows 10 or Windows 11
- WebView2 runtime
- Microphone permission only if Voice Commander is enabled
- Camera permission only if Camera / Hand Control is enabled
