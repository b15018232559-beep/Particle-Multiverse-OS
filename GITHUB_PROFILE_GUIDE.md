# GitHub Profile Guide

Use this guide to make your GitHub profile support Particle Multiverse OS as a portfolio project.

## Name

Use a clear personal or creator name.

Example:

```text
AI Creative Developer
```

## Bio

Keep the bio short and searchable.

Example:

```text
Building cinematic AI interfaces, particle systems, and Tauri desktop apps.
```

## Location

Use a broad location if you want privacy.

Example:

```text
China
```

or:

```text
Remote
```

## Website

Use one of these:

```text
https://github.com/b15018232559-beep/Particle-Multiverse-OS
```

or a personal portfolio site when available.

## Pinned Repositories

Pin repositories in this order:

1. `Particle-Multiverse-OS`
2. Your next strongest visual or AI project
3. A practical app project
4. A library, tool, or template
5. A learning or research project
6. A small polished experiment

## Profile README Template

```md
# Hi, I build cinematic AI interfaces and creative desktop apps.

I focus on particle systems, Tauri apps, cyberpunk UI, local-first tools, and experimental AI interfaces.

## Featured Project

[Particle Multiverse OS](https://github.com/b15018232559-beep/Particle-Multiverse-OS)

A cinematic particle multiverse desktop app built with Tauri, Vite, JavaScript, Canvas, and WebGL-style effects.
```
