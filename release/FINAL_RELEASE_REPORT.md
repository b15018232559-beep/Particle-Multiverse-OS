## 2. Port Strategy Decision

Automatic port switching: not needed.

Reason:

- Tauri config expects `devUrl` at `http://localhost:1420`.
- Vite automatic port switching would make Tauri open the wrong dev URL unless both configs were changed together.
- The correct release fix is to close stale dev instances before launching `tauri dev`.

Old dev instance shutdown: needed and completed.

Impact on `tauri build`: no impact.

Reason:

- `npm run tauri build` uses production build output and does not require the dev server to bind port `1420`.
