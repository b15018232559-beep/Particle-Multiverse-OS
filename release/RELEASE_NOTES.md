# Release Notes

## Particle Multiverse OS V10

V10 is the final consolidation release.

### Added

- Mission Control with `Tab`.
- Command Center unified command dispatch.
- Research Workspace.
- System Command Center Dashboard metrics for Agent, Team, Task, Memory, and Performance.
- System Health Pro checks for Agent, Voice, Memory, and failed tasks.
- Ultimate Scene central core and orbit visualization.
- Final PMOS architecture, user, developer, install, and release documentation.

### Preserved

- V1-V9 worlds, interactions, camera, gesture, music, context, voice, plugins, workspace memory, agent layer, and multi-agent system.
- Single particle render loop.
- Local-only privacy boundary.
